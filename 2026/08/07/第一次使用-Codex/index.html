第一次使用 Codex

Created2026-08-07|Updated2026-08-07|学习记录
|Post Views:

今天第一次使用 Codex，感觉像是多了一个能一起学习、一起做项目的搭子。

一开始我只是想看看自己 GitHub 仓库里有没有东西，结果发现以前搭好的博客网站还在运行。随后我打开了自己的博客页面，看到了以前写过的文章，突然觉得挺有意思：原来我也已经留下过一些学习记录。

Codex 能帮我做什么？

目前我了解到，Codex 可以帮助我做很多事情：

  • 看懂和修改代码；
  • 帮我写博客、整理学习笔记；
  • 管理 GitHub 仓库；
  • 查找报错原因；
  • 把一个模糊的想法变成可以运行的小项目。

对刚开始学习编程的我来说，最重要的不是让 AI 把一切都做完，而是把它当成一个耐心的老师和助手。遇到不懂的地方就问，边做边学，慢慢把知识变成自己的东西。

我的目标

接下来，我希望能坚持记录自己的学习过程：

  1. 继续学好 C 语言，打牢基础；
  2. 学会使用 GitHub 保存代码和博客；
  3. 尝试做一些属于自己的小项目；
  4. 把遇到的问题、学到的知识写成博客。

不怕起步慢，只怕不开始。

这是我第一次使用 Codex，也是我继续学习编程的新起点。以后回头看，希望能感谢今天愿意开始行动的自己。💪
